# 图像模块接口契约

> 适用范围：`server.mjs` 图像路由、`image-providers.mjs` 适配层、`public/app.js` 图像工作台。
> 本文档按当前代码梳理字段、约束、返回与错误码；未实现的能力不列入。

## 1. 通用约定

### 1.1 鉴权与可用性
- 所有 `/api/images/*` 路由纳入 `home` 权限范围，按当前会话用户鉴权；资产按本人隔离，不可跨用户读写。
- 外部模型能力受网络与身份限制：政务网（非 `inet`）、访客用户不可用外部图像模型；无任一已配置模型时整体关闭。
- 未配置对应凭证时，后端返回 `503` 与 `disabledReason`；前端不发请求、不打开空弹窗。

### 1.2 响应形态
- 成功：`{ ok: true, image?: {...}, layers?: [...], comments?: [...], ... }`。
- 失败：`{ error: string, code: string }`，HTTP 状态码与业务错误码一致（400 / 403 / 404 / 413 / 502 / 503 等）。
- 新建版本类操作（编辑、扩图、超清、抠图、标注、缩放、局部重绘）都把结果保存为当前资产的**新版本（revision）**，原图不被覆盖。

### 1.3 图像资产对象（image）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 资产 ID |
| `assetId` | string | 同 `id` |
| `fileId` | string | 当前版本文件 ID |
| `name` | string | 文件名 |
| `mime` | string | `image/png` / `image/jpeg` / `image/webp` |
| `size` | number | 文件字节数 |
| `width` / `height` | number | 像素尺寸 |
| `ratio` | string | `1:1` / `3:4` / `9:16` / `4:3` / `16:9` |
| `style` | string | 风格标签（最长 20） |
| `seed` | number | 随机种子 |
| `prompt` | string | 提示词 |
| `provider` / `providerLabel` | string | 提供方标识与中文名 |
| `model` / `modelId` | string | 模型标识 |
| `revision` | number | 当前版本号（从 1 起） |
| `requestId` | string | 外部请求编号（可空） |
| `cost` | object | 成本计费字段（可空） |
| `url` | string | 可访问的文件地址 |

## 2. 模型与凭证矩阵

### 2.1 生图 / 编辑模型（方舟 / 百炼，Bearer Key）
| 模型 ID | 提供方 | 能力 | 环境变量 |
| --- | --- | --- | --- |
| `qwen-image` | 阿里云百炼 | 生成、编辑、参考图 | `QWEN_IMAGE_API_KEY`、`QWEN_IMAGE_ENDPOINT`、`QWEN_IMAGE_MODEL` |
| `seedream-5.5` | 火山方舟 | 生成、编辑、参考图、图层拆分 | `SEEDREAM_IMAGE_API_KEY`、`SEEDREAM_IMAGE_ENDPOINT`、`SEEDREAM_IMAGE_MODEL` |

- 能力字段 `capabilities`：`generate` / `edit` / `references` / `layers`。
- 模型选择可被 `JG_IMAGE_MODEL`、`JG_IMAGE_PROVIDER` 覆盖；未配置 Key 的模型保持未配置，**不回退**到其他 Provider。

### 2.2 视觉服务（火山视觉，IAM AK/SK 签名，独立于方舟 Key）
| 能力 | req_key | 环境变量 |
| --- | --- | --- |
| 智能扩图 | `i2i_outpainting` | `VOLC_VISUAL_AK`、`VOLC_VISUAL_SK`（必填）；`VOLC_VISUAL_HOST`、`VOLC_VISUAL_REGION`（可选） |
| 智能超清 | `jimeng_i2i_seed3_tilesr_cvtob` | 同上 |

### 2.3 本地能力
| 能力 | 实现 | 依赖 |
| --- | --- | --- |
| 标注合成 | sharp 本地处理 | `dsh-runtime` 内 sharp |
| 画幅比例调整 | AI 定向扩图（火山视觉）/ 图生图兜底（编辑模型） | 火山视觉 / 已配置编辑模型 |
| 移除背景 | mediakit-cli `remove-image-background` | `mediakit-cli` |

### 2.4 模型状态
`GET /api/images/models`
- 返回：`enabled`、`reason`、`defaultModelId`、`models[]`（含 `id/label/provider/providerLabel/model/configured/default/capabilities/keyEnv/disabledReason/available`）、`visual`（`{ configured, akEnv, skEnv, disabledReason }`）。

## 4. 生成与编辑路由

### 4.1 POST `/api/images/generate`
请求体：
| 字段 | 类型 | 必填 | 约束 / 默认 |
| --- | --- | --- | --- |
| `prompt` | string | 是 | 非空，≤1200 字符 |
| `modelId` | string | 否 | 默认选中的已配置模型 |
| `style` | string | 否 | 默认 `写实`，≤20 字符 |
| `ratio` | string | 否 | 默认 `1:1`；须在支持比例内 |
| `seed` | number | 否 | 正整数；缺省随机 |
| `referenceAssetIds` | string[] | 否 | 本人资产 ID；参考图合计 ≤3 |
| `referenceDataUrls` | string[] | 否 | `data:image/...;base64,...`；合计 ≤3 |

返回：`{ ok: true, image, jobId }`。
错误码：`IMAGE_DISABLED`(403)、`IMAGE_PROMPT_REQUIRED`(400)、`IMAGE_PROMPT_TOO_LONG`(400)、`IMAGE_REFERENCE_TOO_MANY`(400)、`IMAGE_REFERENCE_INVALID`(400)。

### 4.2 POST `/api/images/edit`（整图 AI 重绘）
请求体：`assetId`(string, 必填)、`prompt`(string, 必填, ≤1200)、`modelId`(string, 可选)、`seed`(number, 可选)。
- 仅选 `configured && capabilities.edit` 的模型；模型不支持编辑或未配置时返回对应错误。
返回：`{ ok: true, image }`。
错误码：`IMAGE_DISABLED`、`IMAGE_ASSET_REQUIRED`、`IMAGE_EDIT_PROMPT_REQUIRED`、`IMAGE_EDIT_PROMPT_TOO_LONG`、`IMAGE_ASSET_NOT_FOUND`(404)、`IMAGE_FILE_NOT_FOUND`(404)、`IMAGE_MODEL_NOT_CONFIGURED`(503)、`IMAGE_EDIT_UNSUPPORTED`(400)、`IMAGE_EDIT_UNAVAILABLE`(400)。

### 4.3 POST `/api/images/mask-edit`（选区局部重绘）
请求体：
| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `assetId` | string | 是 | 本人资产 |
| `prompt` | string | 是 | ≤800 字符 |
| `maskDataUrl` | string | 是 | `data:image/(png|jpeg|webp);base64,...`；非空；≤10 MB |
| `modelId` | string | 否 | 编辑模型 |

- 选区外像素由服务端按 Mask 合成保留；选区内交给模型重绘。
错误码：`IMAGE_ASSET_REQUIRED`、`IMAGE_REGION_PROMPT_REQUIRED`、`IMAGE_REGION_PROMPT_TOO_LONG`、`IMAGE_REGION_MASK_INVALID`、`IMAGE_REGION_MASK_EMPTY`、`IMAGE_REGION_MASK_TOO_LARGE`(413)、`IMAGE_ASSET_NOT_FOUND`、`IMAGE_FILE_NOT_FOUND`、`IMAGE_MODEL_NOT_CONFIGURED`、`IMAGE_EDIT_UNSUPPORTED`。

### 4.4 POST `/api/images/annotate`
请求体：`assetId`(必填)、`dataUrl`(标注画布 data URL)、`width`、`height`。
- 标注画布尺寸须与原图一致；本地 sharp 合成 PNG 存为新版本。
错误码：`IMAGE_ASSET_NOT_FOUND`、`IMAGE_EDIT_UNAVAILABLE`(503)、`IMAGE_ANNOTATION_INVALID`、`IMAGE_ANNOTATION_FAILED`。

### 4.5 POST `/api/images/resize`（AI 调整画幅）
请求体：`assetId`(必填)、`ratio`(必填，预设比例)。
- AI 按目标比例调整画幅：优先火山视觉定向外扩（保短边、主体不缩小，仅延展背景）；视觉不可用或失败时，回退编辑模型以原图为参考按目标比例重绘。
- 不再使用本地 sharp 透明画布 contain 缩放。
错误码：`IMAGE_ASSET_NOT_FOUND`、`IMAGE_RESIZE_RATIO_INVALID`(400)、`IMAGE_RESIZE_SAME_RATIO`(400)、`IMAGE_RESIZE_UNAVAILABLE`(503，无可用 AI 画幅模型)、`IMAGE_RESIZE_FAILED`(502/500)。

### 4.6 POST `/api/images/remove-bg`
请求体：`assetId`(必填)、`scene`(`general` / `human` / `product`，默认 `general`)。
- 走 mediakit-cli，输出透明 PNG，存为新版本。

### 4.7 POST `/api/images/expand`（智能扩图）
请求体：
| 字段 | 类型 | 必填 | 约束 / 默认 |
| --- | --- | --- | --- |
| `assetId` | string | 是 | 本人资产 |
| `expand` | number | 否 | 单边比例，钳制 0.05–1，默认 0.1；前端档位 0.1 / 0.2 / 0.3 |
| `prompt` | string | 否 | 延展方向提示，≤100 字符 |
| `maxWidth` / `maxHeight` | number | 否 | 640–4096，默认 1920 |

- 四边使用同一 `expand` 等比外扩；原图保持不变。
返回：`{ ok: true, image }`。
错误码：`IMAGE_ASSET_NOT_FOUND`、`IMAGE_VISUAL_NOT_CONFIGURED`(503)、`IMAGE_EXPAND_FAILED`(502/400)。

### 4.8 POST `/api/images/upscale`（智能超清）
请求体：
| 字段 | 类型 | 必填 | 约束 / 默认 |
| --- | --- | --- | --- |
| `assetId` | string | 是 | 本人资产 |
| `resolution` | string | 否 | `4k` / `8k`，默认 `4k` |
| `scale` | number | 否 | 0–100，默认 50；前端档位 30 / 50 / 80 |

- 异步：先提交任务取 `task_id`，再轮询结果；`in_queue` / `generating` 继续等待，`done` 取图，`not_found` / `expired` 报错。
错误码：`IMAGE_ASSET_NOT_FOUND`、`IMAGE_VISUAL_NOT_CONFIGURED`(503)、`IMAGE_UPSCALE_NO_TASK`(502)、`IMAGE_UPSCALE_TASK_LOST`(502)、`IMAGE_UPSCALE_TIMEOUT`(502)。

## 5. 图层模块

### 5.1 图层对象（layer）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 图层 ID |
| `assetId` | string | 所属资产 ID |
| `kind` | string | `background` / `layer` |
| `name` | string | 图层名（≤40） |
| `description` | string | 描述（≤200） |
| `zOrder` | number | 层级顺序，背景为 0 |
| `url` | string | 图层图片地址 |
| `box` | object | `{ normalized: [l, t, r, b], absolute: [x, y, w, h]? }`；归一化相对画布 0–1 |
| `rotation` | number | 旋转角度（0–359，度） |
| `visible` | boolean | 是否显示 |
| `opacity` | number | 0–100 |
| `blendMode` | string | `normal` / `multiply` / `screen` / `overlay` / `darken` / `lighten` |
| `locked` | boolean | 是否锁定（背景层恒锁定） |
| `provider` / `model` / `modelId` | string | 拆分来源 |

### 5.2 GET `/api/images/layers`
Query：`assetId`。返回：`{ ok: true, layers: [...] }`。

### 5.3 POST `/api/images/layers/decompose`
请求体：`assetId`(必填)、`prompt`(可选)、`modelId`(可选)。
- 调用 Seedream `layer_decomposition` 拆分；先清空该资产旧图层，再落背景层 + 各图层。
返回：`{ ok: true, layers: [...] }`。

### 5.4 PATCH `/api/images/layers`
请求体：`id`(必填) + 下列可选字段（仅传需要更新的项）：
`name`、`visible`、`opacity`(0–100)、`blendMode`、`locked`、`description`、`zOrder`、`rotation`(角度，归一化到 0–359)、`box`(`{ normalized: [l,t,r,b] }`，须满足 `r>l && b>t`)。
返回：`{ ok: true, layer }`。
错误码：`IMAGE_LAYER_NOT_FOUND`(404)、`IMAGE_LAYER_UPDATE_FAILED`(500)。

### 5.5 POST `/api/images/layers/reorder`
请求体：`assetId`、`layers: [{ id, zOrder }]`。返回：`{ ok: true, layers: [...] }`。

### 5.6 DELETE `/api/images/layers`
请求体：`id`。背景层不可删除（`IMAGE_LAYER_LOCKED`）。返回：`{ ok: true, id }`。

### 5.7 前端画布交互（与 `box` / `rotation` 的关系）
- `box.normalized` 保存**未旋转**的自身矩形；旋转通过 `rotation` 绕中心实现。
- 移动时按旋转外接矩形（AABB）做越界钳制；支持对齐画布中线与其他图层边缘。
- 缩放：默认自由缩放；按住 `Alt` 以中心对称缩放；旋转态下指针先转到图层局部坐标系再算缩放。
- 导出合成：按 `zOrder` 排序，应用透明度、混合模式与绕中心旋转绘制，输出 PNG。

## 6. 评论、版本与模板

### 6.1 评论
- `GET /api/images/comments?assetId=` → `{ ok: true, comments: [...] }`。
- `POST /api/images/comments`：`assetId`、`body`(必填, ≤500)。返回 `{ ok: true, comment }`。
错误码：`IMAGE_ASSET_NOT_FOUND`、`IMAGE_COMMENT_REQUIRED`、`IMAGE_COMMENT_TOO_LONG`。

### 6.2 版本
- `GET /api/images/recent?limit=`（1–50，默认 20）→ 当前用户最近图像。
- `POST /api/images/restore`：`assetId`、`revision`（正整数）。恢复不覆盖历史，而是新增一条指向目标版本文件的修订号。
错误码：`IMAGE_RESTORE_TARGET_REQUIRED`、`IMAGE_ASSET_NOT_FOUND`、`IMAGE_REVISION_NOT_FOUND`、`IMAGE_REVISION_ALREADY_CURRENT`、`IMAGE_FILE_NOT_FOUND`、`IMAGE_RESTORE_FAILED`(409)。

### 6.3 模板
- `GET /api/images/templates`：已审核模板。
- `POST /api/images/template-applications`：`title`(必填, ≤40)、`category`(受支持分类)、`prompt`(必填, ≤2000)、`description`(≤800)、`sourceAssetId`(本人资产)；来源图 ≤8 MB。
- `POST /api/images/template-review`：后台审核通过 / 驳回。
- `POST /api/images/template-delete`：删除模板。
- `GET /api/images/template-preview?fileId=`：模板预览图。

## 8. 已知边界

- 对齐吸附目前作用于移动；缩放吸附仅对齐右 / 下边缘。
- 图层 `box` 保存未旋转矩形，旋转外接矩形为前端派生量，不回写库。
- 本地无 SAM / 多实例分割库；图层拆分依赖外部 Seedream 模型。
- 外部模型与火山视觉的真实端到端调用需对应凭证；无凭证时接口返回 503，前端仅提示原因。
