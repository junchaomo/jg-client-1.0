## 5. 已验证与未验证边界

### 已验证
- 后端路由、请求字段校验、错误码与 `docs/图像模块接口契约.md` 一致。
- 模型能力矩阵（生成 / 编辑 / 参考图 / 图层）由适配层定义并经单测覆盖。
- 图层数据模型、更新 / 重排 / 删除规则（背景层不可删）经单测与静态审查确认。
- 服务可启动、静态可访问、接口鉴权拦截正常。

### 未端到端实测（受限，如实标注）
- **外部生图 / 编辑 / 图层拆分的真实联网调用**：本次未在测试环境实际请求百炼 / 方舟接口；仅以单测 mock 外部响应做参数与分支验证。真实出图效果、网络可达性、计费与并发未验证。
- **火山视觉扩图 / 超清**：AK/SK 未配置，未发起真实签名请求；签名、任务轮询分支由单测 mock 覆盖。

- 如需真实端到端验收，需：配置对应凭证、具备外网 / 政务网可达性，并在登录会话下走完整「入口 → 生成 → 落库 → 展示」链路。

## 6. 已知限制（继承自实现）

- 对齐吸附作用于移动；缩放吸附仅对齐右 / 下边缘；旋转态缩放走局部坐标中心锚定，未做边缘吸附。
- 图层 `box` 保存未旋转矩形，旋转外接矩形为前端派生量，不回写库。
- 本地无 SAM / 多实例分割库；图层拆分依赖外部 Seedream 模型。
