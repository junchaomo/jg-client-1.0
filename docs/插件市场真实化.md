# 插件市场真实化（技能包闭环）

> 日期：2026-11-12  
> 目标：把“插件市场”从只改安装标记，改成安装后模型真的能发现和调用的技能。

## 一、现在能做什么

1. **市场浏览**：热门 / 新品推荐 / 企业内部三个分区，卡片、详情、已安装列表。
2. **内置技能安装**：5 个真实技能包，点击“安装”后复制到 `$DSH_HOME/skills/market-<ID>`；下一轮对话自动重新加载。
3. **卸载**：只删除带 `.jg-market.json` 市场标记的目录，不会误删 `jg-product` 或其他手工技能。
4. **上传技能包**：ZIP 根目录含 `SKILL.md`，经静态检测、管理员审核后入库到 `data/market-packages/<PLG-ID>`，随后可在市场安装。
5. **状态真实**：`installed` 由技能目录与市场清单实时计算，不再使用内存 Map 假装安装。
6. **未提供包的条目显示“待上架”**，不再出现“点了安装但什么都没发生”。

## 二、内置 5 个技能包

| 市场 ID | 名称 | 技能名 | 能做什么 |
|---|---|---|---|
| M-01 | 规范条文核查 | `code-compliance-check` | 对规划/建筑/市政图纸与文本做条文级核查，输出问题清单、依据、位置与整改建议 |
| M-02 | 用地指标测算 | `land-use-metrics` | 测算容积率、建筑密度、绿地率、人均公共绿地，输出计算过程与校核项 |
| M-03 | 公文格式校对 | `gov-doc-format-check` | 按 GB/T 9704 校对版头、发文字号、标题、主送、附件、落款、页码 |
| M-07 | 会议纪要整理 | `meeting-minutes` | 把转写/笔记整理成议定事项、责任人、时限与待确认问题 |
| M-08 | 合同条款比对 | `contract-clause-compare` | 比对合同两版条款，标记付款、工期、违约、知识产权、保密风险 |

源文件在 `marketplace/skills/<ID>/SKILL.md`，可随仓库版本管理。

## 三、技能包规范

```
my-skill.zip
├─ SKILL.md             必需，含 frontmatter: name / description
├─ references/          可选，参考文档
└─ assets/              可选，图片等素材
```

允许的文件类型：`.md`、`.txt`、`.json`、`.csv`、`.yml/.yaml`、`.png/.jpg/.jpeg/.gif/.webp/.svg`、`.pdf`。

不允许：`.js/.mjs/.cjs/.ts/.py/.ps1/.bat/.cmd/.exe/.dll/.so` 等可执行文件；路径跳转（`..`）、绝对路径；外部网络地址。

检测项：

- 技能包格式：根目录有且只有一个 `SKILL.md`
- 技能元信息：frontmatter 的 `name`、`description` 完整
- 权限声明：不注册可执行工具，只提供提示词与参考文件
- 静态安全扫描：无可执行文件、无外部网络地址、无路径越界
- 隔离测试：技能包不执行代码，安装后由运行时按技能规则加载

## 四、接口与落盘位置

| 接口 | 作用 |
|---|---|
| `GET /api/plugin-market` | 返回 `available`、`installed`、`installScope`，状态由文件系统计算 |
| `POST /api/plugin-market/install` | 安装/卸载；复制或删除 `$DSH_HOME/skills/market-<ID>`；关闭空闲运行时 |
| `POST /api/plugin-subs` | 上传 ZIP 后提交检测，记录 `kind: skill/bundle` |
| `POST /api/plugin-subs/review` | 审核通过；技能包解压到 `data/market-packages/<PLG-ID>`，加入市场 |

落盘：

- 内置技能源：`marketplace/skills/<ID>/`
- 上传技能包：`data/market-packages/<PLG-ID>/`
- 运行时挂载：`data/dsh-home/skills/market-<ID>/`
- 市场安装标记：`.jg-market.json`（marketId、version、installedAt、installedBy）

## 五、安全与边界

- **安装是全局的**：DSH_HOME 共享，技能安装后同一客户端所有账号都能看到；当前不是按账号隔离。
- **安装/卸载时会关闭空闲 Harness 运行时**：如果 `activeRuns` 非空，接口直接返回 409，不打断正在执行的任务。
- **DSH Bundle 仍未一键安装**：客户端没有 pnpm，`dsh plugin add` 走不通；Bundle 审核后只上架登记，卡片显示“待上架”。
- **卸载保护**：没有市场清单的目录拒绝删除；同名目录不会被覆盖。
- **技能不是工具**：技能只影响模型的工作方法，不能执行自定义 JS；需要真实系统调用时走产品 MCP 工具。

## 六、已验证

1. 市场列表返回 5 个内置条目，均 `available: true`；M-01、M-03 安装后 `installed: true`。
2. 点击市场卡片“安装”，侧栏“已安装”立即出现对应技能。
3. `data/dsh-home/skills` 出现 `market-M-01`、`market-M-03`，卸载 M-07 后目录消失。
4. 新会话让模型列出技能，回复中出现 `code-compliance-check`，说明运行时真实发现。
5. 上传 `market-smoke-test.zip` → 检测 4 项通过 → 管理员审核 → `data/market-packages/PLG-01/SKILL.md` → 安装 → `market-PLG-01`，闭环通过；测试数据已清理。
