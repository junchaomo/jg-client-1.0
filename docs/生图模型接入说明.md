# 生图模型 Provider 接口与配置说明

日期：2026-11-15

## 本轮范围

本轮只完成“生图专用模型调用”的最小接口，不接入聊天模型网关，不引入通用多模态网关：

- 服务端新增独立 Provider 适配层 `image-providers.mjs`。
- 当前只注册两家图像模型：阿里云百炼 Qwen-Image、火山方舟 Seedream。
- 模型 Key 未配置时不启用生图；不生成假图，不回退 Pollinations，也不使用聊天模型冒充图像模型。
- 图片页只展示真实生成结果；用户可在图片页选择实际使用的图像模型。
- 图片历史持久化与 Qwen 单模型真实编辑已接通；局部选区、版本回退、多参考图仍不在本轮范围内。

## 环境变量

### Qwen-Image

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `QWEN_IMAGE_API_KEY` | 是 | 无 | 阿里云百炼 API Key，只保存在服务端 |
| `QWEN_IMAGE_ENDPOINT` | 否 | `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` | 建议替换为业务空间专属地址 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` |
| `QWEN_IMAGE_MODEL` | 否 | `qwen-image-3.0-pro` | 可改为 `qwen-image-3.0` 等已开通模型 |

调用形态为 DashScope 同步接口：文生图使用 `input.messages[].content[].text` 传入提示词；图像编辑使用 `{ image: "data:image/png;base64,..." }` 再跟 `{ text: "编辑要求" }` 的内容顺序。`parameters.size` 使用 `宽*高`；响应读取 `output.choices[0].message.content[].image`。返回图像 URL 约 24 小时有效，服务端会立即下载并写入现有文件存储，不把临时 URL 作为长期作品地址。

### Seedream

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `SEEDREAM_IMAGE_API_KEY` | 是 | 无 | 火山方舟 API Key，只保存在服务端 |
| `SEEDREAM_IMAGE_ENDPOINT` | 否 | `https://ark.cn-beijing.volces.com/api/v3/images/generations` | 方舟图片生成接口 |
| `SEEDREAM_IMAGE_MODEL` | 否 | `doubao-seedream-5-5-261028` | 可改为已开通的 Seedream Model ID / Endpoint ID |

调用形态为方舟 `POST /api/v3/images/generations`：请求体使用 `prompt`、`size`、`output_format`、`response_format`；响应优先读取 `data[].url`，也兼容 `data[].b64_json`。

> 重要：火山方舟的“充值”不会自动开通模型服务。首次使用 Seedream 5.5 时，需要在方舟控制台进入“模型服务/开通管理”，找到 `Doubao Seedream 5.5` 并点击“开通服务”；如果 API Key 使用自定义权限，还要确认该 Key 所属项目允许调用这个模型。否则接口会返回 `The model or endpoint ... does not exist or you do not have access to it`，系统会归一化为 `IMAGE_PROVIDER_MODEL_NOT_ACCESSIBLE`。
>
> 模型开通状态按火山账号和项目生效，不会继承到其他账号或项目的旧 Key。若控制台显示“已开通”但接口仍返回无访问权，先确认当前登录账号的 API Key 列表是否包含这把 Key；列表为空或 Key 来自其他项目时，应在已开通模型的项目下重新创建 Key（权限至少覆盖目标模型），再替换 `SEEDREAM_IMAGE_API_KEY`。

### 默认模型与用户选择

| 变量 | 必填 | 说明 |
|---|---|---|
| `JG_IMAGE_MODEL` | 否 | 默认模型 ID，可填 `qwen-image` 或 `seedream-5.5` |
| `JG_IMAGE_PROVIDER` | 否 | 默认 Provider，可填 `qwen` 或 `seedream`；与 `JG_IMAGE_MODEL` 同时存在时以 `JG_IMAGE_MODEL` 为准 |
| `JG_IMAGE_TIMEOUT_MS` | 否 | 单次 Provider 调用超时，默认 120000 毫秒，限制在 30000–300000 |
| `JG_IMAGE_EDIT_TIMEOUT_MS` | 否 | 图像编辑调用超时，默认 240000 毫秒，限制在 30000–300000 |

如果两家 Key 都配置，图片页会同时显示两个模型并允许切换；如果只配置一家，只启用该模型，另一家显示“未配置”。用户选择只影响本次生成请求，不改动聊天模型。

## 接口

### `GET /api/images/models`

返回当前网络和用户可见的图像模型目录，不返回 Key。关键字段：

```json
{
  "enabled": true,
  "defaultModelId": "qwen-image",
  "models": [
    {
      "id": "qwen-image",
      "label": "Qwen-Image 3.0 Pro",
      "provider": "qwen",
      "model": "qwen-image-3.0-pro",
      "configured": true,
      "available": true
    }
  ]
}
```

### `POST /api/images/generate`

在原请求体上新增可选 `modelId`；不传时使用 `defaultModelId`。服务端会再次检查模型是否已配置、网络域是否允许、用户是否已登录，然后调用对应 Provider，并把结果写入现有 `files` 表。

```json
{
  "prompt": "现代文化中心建筑方案意向图",
  "ratio": "16:9",
  "style": "效果图",
  "modelId": "qwen-image"
}
```

### `POST /api/images/edit`

把已有图片资产作为输入，调用支持编辑的 Provider 生成一个新版本。请求体：

```json
{
  "assetId": "IMG-MWH6CM3S-0C2F2189",
  "prompt": "把建筑外墙改成暖灰色石材，保留构图、树木和道路",
  "modelId": "qwen-image"
}
```

服务端按当前登录用户校验资产归属，读取资产最新文件，以 Base64 data URL 提交给 Qwen-Image 编辑接口；成功后创建新的 `image_revision`、更新资产最新文件，并写入一条 `kind="edit"` 的 `image_jobs`。原图仍保留在版本历史中。当前仅 Qwen-Image 的 `capabilities.edit` 为 `true`，Seedream 编辑会明确返回 `IMAGE_EDIT_UNSUPPORTED`，不会回退到其他 Provider。

图像编辑输入限制为 10 MB、PNG/JPEG/WebP；默认关闭 `prompt_extend`，避免编辑时开启额外思考导致超时。

## 安全约束

- Key 只在服务端环境变量中读取，前端目录接口不返回 Key、Endpoint 或完整请求头。
- 只在互联网网络域启用；政务外网/涉密内网不把提示词发送到公共云生图 API。
- 外部访客不启用。
- 生成结果下载后校验 MIME 类型和大小（8 KB–24 MB），失败不会写入文件表。
- 没有配置模型的请求返回 `IMAGE_MODEL_NOT_CONFIGURED`，不会回退到其他 Provider。
- 当前开放 Qwen-Image 全图编辑（`capabilities.edit=true`）；Seedream 编辑仍未开放。编辑必须携带当前图片文件作为输入并创建新版本，不能把“改提示词重新生成”当成图像编辑；局部选区与版本回退仍属后续阶段。


测试使用本地 mock HTTP 服务验证两家 Provider 的请求形态、Qwen Base64 编辑输入、响应解析、图片下载和未知模型/未开放编辑的拒绝，不发起真实外部调用，也不需要真实 Key。
