# 合同条款比对

## 输入

- 合同版本 A（基准版）与版本 B（修订版），或用户指定的两个版本。
- 合同类型、甲方/乙方立场、关注重点（付款、工期、违约责任、知识产权、保密、终止、争议解决等）。

材料不完整时先列缺项，不根据单版合同推测另一版内容。

## 比对流程

1. **确认版本**：记录两版的文件名、日期、版本号；无法确认先后时，请用户指定基准版。
2. **建立条款索引**：按章、条、款编号对齐；编号不一致时按内容主题对齐，并标注“编号不可直接对应”。
3. **逐条比对**：判定为“新增 / 删除 / 修改 / 表述调整 / 无变化”。
4. **风险标记**：重点检查：
   - 付款节点、比例、发票与验收条件
   - 工期/服务期、延期责任与免责
   - 违约责任、赔偿上限、违约金
   - 知识产权归属与使用许可
   - 保密义务、数据与个人信息
   - 终止、解除、续约与移交
   - 争议解决方式与管辖
5. **输出修订清单**：每条给出原文摘录、变化说明、影响判断和建议关注方（商务/法务/技术/财务）。

## 输出格式

| 序号 | 条款位置 | 变化类型 | 版本 A 原文要点 | 版本 B 原文要点 | 风险等级 | 影响与建议 |
|---|---|---|---|---|---|---|

最后单列：

- **重大变化**：可能改变权利义务平衡的条款。
- **表述替换但实质未变**：避免用户误判。
- **无法判断**：缺少附件、报价表、技术方案等。

## 边界

- 只做文本比对与风险提示，不构成法律意见，不代替法务审查。
- 不编造条款原文；引用时保留关键限定词。
- 两版条款编号错位时，明确说明对齐依据。
- 涉及金额、比例、日期时原样保留，不做未经确认的换算。
