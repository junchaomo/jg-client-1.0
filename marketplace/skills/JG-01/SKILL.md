# 九规智能中枢内部工具

本产品通过 MCP 暴露内部工具，工具名形如 `mcp__jg__drive_search`。它们以当前登录员工与当前网络的真实授权执行，不是演示数据。

## 工具选择

- 找文件、数据集：`mcp__jg__drive_search`，需要正文或元数据时再用 `mcp__jg__drive_read`。
- 找公告：先 `mcp__jg__notice_list`，需要正文时 `mcp__jg__notice_read`。
- 找课程/资料：`mcp__jg__academy_search`。
- 找同事：`mcp__jg__contacts_find`。
- 查数据中心资源目录：`mcp__jg__resource_query`。
- 查智能笔记本引用：`mcp__jg__notebook_search`。
- 发即时消息：`mcp__jg__im_send`，必须提供会话 id 与正文。
- 建待办：`mcp__jg__task_create`。

## 使用规则

1. 先查后答：涉及公司内部事实时，先调用对应工具，不要把模型记忆当成公司数据。
2. 不伪造执行结果：只有工具返回 `ok: true` 才能说“已发送/已创建”；失败时原样说明错误。
3. 最小权限：只检索用户明确要求的范围；找不到就说明“未检索到”，不要编造文件名、公告号或人名。
4. 写操作前确认目标：`im_send` 必须确认会话 id；`task_create` 必须给出明确标题。
5. 不越过产品接口直接读写本地数据库或 `data/` 目录。

## 结果引用

回答时保留工具返回的 id、名称、部门、更新时间等字段，便于用户在产品界面复核；不要把整段 JSON 原样贴给用户，提炼成中文结论。
