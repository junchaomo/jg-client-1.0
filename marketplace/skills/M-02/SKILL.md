# 用地指标测算

## 输入

至少需要：

- 总用地面积（平方米）
- 建筑基底面积（平方米）
- 地上建筑面积（平方米）
- 绿地面积（平方米）
- 居住户数或规划人口（按需）

缺项时先列缺项，不得用猜测值补齐。

## 计算口径

- 容积率 = 地上建筑面积 ÷ 总用地面积
- 建筑密度 = 建筑基底面积 ÷ 总用地面积 × 100%
- 绿地率 = 绿地面积 ÷ 总用地面积 × 100%
- 人均公共绿地 = 公共绿地面积 ÷ 规划人口（需要单独区分“公共绿地”和“绿地”）

如项目包含不计容面积、地下建筑面积、代征用地、分期用地，必须先把“计容口径”和“用地口径”确认清楚，再计算。

## 输出格式

1. **输入表**：列出每项数据、单位、来源（用户提供/图纸标注/推算）。
2. **计算表**：

| 指标 | 公式 | 计算结果 | 单位 | 校核 |
|---|---|---|---|---|

3. **与控规条件对比**（用户提供上限/下限时）：逐项给出“满足 / 超出 / 不足 / 无法判定”。
4. **风险提示**：口径不一致、分期用地、地下面积、公共绿地认定、四舍五入误差。

## 边界

- 只做指标测算与校核，不替代规划许可或用地审批。
- 不把“用地面积”和“建设用地面积”“代征用地”混用。
- 所有结果保留计算过程，便于人工复核。
- 用户未提供控规条件时，不判断“合规”，只给测算值。
